# 责任边界

## 区分五种角色

- **提出需求**：说明要解决的问题和预期结果。
- **决策批准**：在授权范围内选择方案并接受相应决策后果。
- **执行实施**：按确认的方案开展工作，并报告执行中发现的问题。
- **专业评估**：提供技术、风险、法律或业务方面的分析意见。
- **验收确认**：依据约定标准确认交付结果。

一个人可能承担多个角色，但角色应明确，不能仅凭职位、口头印象或事后推断确定。

## 哪些事情需要额外确认

- 涉及预算、业务规则或范围变更的决策
- 生产环境操作和高风险配置变更
- 涉及个人信息、客户数据或机密资料的处理
- 需要例外审批或偏离标准流程的情况
- 影响多个团队交付承诺的优先级调整

## 合理承担自己的责任

如果自己有遗漏：

1. 说明具体事实，不夸大也不淡化。
2. 立即采取适当补救措施。
3. 通知相关负责人并评估影响。
4. 记录原因和改进措施。
5. 跟踪改进是否有效。

## 对不准确的责任认定提出异议

1. 请求说明具体事项、适用标准和事实依据。
2. 整理相关任务安排、决策、操作和沟通记录。
3. 区分个人可控事项、外部依赖和共同决策。
4. 用书面、专业的方式说明差异并提出复核请求。
5. 需要时使用组织内正式申诉、合规或劳动权益渠道。

不要通过删改记录、攻击他人或泄露机密来证明自己正确。

## 重要提醒

书面记录可以帮助还原事实，但不自动免除责任；领导确认也不必然使违法或违反强制安全要求的操作变得正当。责任认定应结合事实、实际权限、适用规则和具体情况。
