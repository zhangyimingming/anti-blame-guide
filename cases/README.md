# 脱敏案例库

本目录用于整理具有普遍参考价值的职场协作、项目风险和故障复盘案例。

## 案例模板

- **场景**：发生了什么？
- **背景**：项目类型、角色和必要上下文（避免可识别细节）
- **问题**：责任边界或流程上存在什么不清楚之处？
- **经过**：按时间顺序描述可核实事实
- **处理方式**：采取了什么措施？
- **复盘**：哪些机制可以改进？
- **可复用建议**：其他人可以如何应用？

## 隐私与合规要求

请勿提交真实姓名、具体公司或客户名称、邮箱、电话号码、账号、内部系统地址、凭证、个人信息、商业秘密或未经授权取得的材料。即使删掉姓名，如果上下文仍能识别当事人，也不要公开提交。

案例应区分事实、个人观点和未证实的推测。不得将本目录用于曝光、骚扰或羞辱特定个人。
